AI Label OCR System

Clean Architecture & Repository Pattern OCR System with TypeScript, Tesseract.js, and Microsoft SQL Server

language: TypeScript (Node.js 22+)framework: Express.jsocrEngine: Tesseract.js (Offline Local OCR)database: Microsoft SQL Server (mssql)orm: TypeORM (Repository Pattern)validation: ZoddiagramTool: Archify

Architectural Layers & Repositories

Presentation / Interface Layer

  • Express HTTP Server Server
  • LabelController Controller
  • Multer Upload Middleware Middleware
  • Global Error Middleware Middleware

Application Layer

  • LabelScanService Service
    Orchestrates OCR, parsing, database persistence, and audit logging
  • DTOs & Validation DTO
    Defines input/output contracts and Zod schema validation

Domain Layer

  • Label Entity Entity
    Core business model for scanned labels
  • ScanLog Entity Entity
    Audit trail for OCR execution metrics
  • ILabelRepository Interface
    Repository contract for Label persistence
  • IScanLogRepository Interface
    Repository contract for ScanLog persistence

Infrastructure Layer

  • TesseractOCRService OCR Engine
    Offline optical character recognition worker
  • LabelParserService Parser
    Extracts barcode, lot, dates, product names, weight via regex heuristics
  • TypeORMLabelRepository Repository
    Concrete TypeORM repository implementing ILabelRepository
  • TypeORMScanLogRepository Repository
    Concrete TypeORM repository implementing IScanLogRepository
  • Microsoft SQL Server Database
    Relational storage for Labels and ScanLogs

End-to-End Scan & Database Flow

Step 1
Client / Scanner → upload_mw
Upload label image (POST /api/v1/labels/scan)
Step 2
upload_mw → label_ctrl
Forward uploaded file buffer/path
Step 3
label_ctrl → scan_service
Invoke scanAndSaveLabel(filePath, options)
Step 4
scan_service → tesseract_service
Execute OCR text extraction
Step 5
tesseract_service → parser_service
Pass raw text and line confidence to parser
Step 6
parser_service → scan_service
Return structured LabelParsedData
Step 7
scan_service → typeorm_label_repo
Insert/Update Label record in SQL Server
Step 8
scan_service → typeorm_log_repo
Record ScanLog with execution metrics
Step 9
scan_service → label_ctrl
Return saved Label and extraction metadata
Step 10
label_ctrl → Client / Scanner
HTTP 201 Response with structured JSON
